# Changelog

## 0.1.0

- Generate a continuous honeycomb grid across one or more selected straight-edged regions in an open sketch.
- Set hexagon size, spacing, orientation, rotation, grid anchor, and X/Y offsets.
- Keep only complete cells or trim cells at the boundary. Set an optional inset to leave a border.
- Edit the size and gap of complete cells through SolidCraft's Parameters panel.
- Preview the pattern on SolidCraft builds that support plugin sketch previews.
